# lawfocus web

Vue 3 + Vite + TypeScript frontend for the 经济法知识图谱与上市公司治理合规推理系统 MVP.
See the [repo root README](../../README.md) for architecture, setup, and demo accounts.

```bash
pnpm install
pnpm dev      # http://localhost:5173, expects the API on :8000
pnpm test     # vitest
pnpm build    # type-check + production build
pnpm lint     # eslint + vue-tsc
```
