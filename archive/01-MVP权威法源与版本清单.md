# MVP 权威法源与版本清单

> 基线日期：2026-07-17。本文确定法源准入、版本记录和首批采集范围；具体条款绑定仍须法律审核。

## 1. 准入原则

1. 原文仅从制定机关、国家法律法规数据库或证券交易所官网获取。
2. 每次采集生成独立 `LegalVersion`，保存原文件、正文哈希、公布日、施行日、失效日和来源 URL。
3. 不覆盖旧版本；评价时按案件事实时间和规则有效时间选择版本。
4. 征求意见稿、新闻解读和二手转载只能作为研究资料，不得编译为正式规则。

## 3. 分板块策略

MVP 默认以沪深主板共同要求为核心。科创板、创业板、北交所规则分别建规则集，不得把某一板块规则直接应用于其他板块。公司所属市场和板块缺失时，交易所规则返回 `UNKNOWN`，而非猜测适用范围。

## 4. 采集验收

- [ ] 官方 URL 可访问，原始附件已保存且 SHA-256 已记录。
- [ ] 公布、施行、失效和过渡期分别建模。
- [ ] 目录、章、节、条、款、项层级可定位。
- [ ] 新旧版本差异可追踪，旧版未被覆盖。
- [ ] 法律审核者确认版本状态后方可标记 `VERIFIED`。

## 5. 更新责任

法律知识工程师每周检查证监会及交易所规则更新；法律审核者确认效力和过渡安排；系统管理员执行发布。发现新版本后先冻结相关规则自动发布，完成差异评估、回归测试和审核后再切换规则集。
