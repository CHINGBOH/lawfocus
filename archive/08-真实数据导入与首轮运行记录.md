# 真实数据导入与首轮运行记录

## 目标与边界

本轮将“骨架可运行”推进到“真实材料可追溯地进入数据库并参与推理”。样本包括现行《中华人民共和国公司法》与贵州茅台酒股份有限公司（上交所代码 600519）2025 年年度报告。

所有机器解析记录先标记为 `UNVERIFIED`。当前 `MVP-P0-DEMO/v1` 的法源绑定仍是演示数据，因此运行结果只证明数据链路和规则引擎可用，不构成正式法律意见。

## 数据来源与完整性

| 数据 | 权威来源 | 本地文件 | 校验 |
|---|---|---|---|
| 公司法（2023 年修订） | 国家法律法规数据库；政府站点正文 | `data/official/company-law-2023/company-law-2023.html` | SHA-256 与 `data/official/manifest.json` 一致；解析 266 条 |
| 贵州茅台 2025 年报 | 上海证券交易所披露文件 | `data/official/companies/600519/annual-report-2025.pdf` | SHA-256 与 manifest 一致 |

年报抽取的报告期末事实：董事会 7 人，其中独立董事 3 人、职工董事 1 人；设置审计委员会；审计委员会成员为王鑫、郭田勇、盛雷鸣。年报摘录未明确召集人，禁止推断该字段。

## 执行方法

先确保数据库已启动且已执行项目 seed，然后运行：

```bash
cd apps/api
uv run pytest tests/unit/test_official_import_parser.py -q
uv run python -m scripts.import_official_sample
uv run python -m scripts.run_official_sample
```

导入脚本是幂等的；重复执行不会重复创建同一法律版本、条文、主体、组织、任职或事实。来源文件哈希不一致时，脚本会在写库前失败。

## 首轮验收标准

- 公司法正文解析并写入 266 个 `ArticleVersion`。
- 公司主体标识为 `LISTED_COMPANY`，交易标识为 `SSE:600519`。
- 董事会、审计委员会、7 名董事和 3 名委员会成员可查询。
- 董事会构成事实与年报证据建立 `DIRECT` 支持关系。
- 三条已发布演示规则能够生成 `ComplianceCheck → Conclusion → Proof → ProofStep` 完整链路。
