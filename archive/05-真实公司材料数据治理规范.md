# 真实公司材料数据治理规范

> 真实公司材料可能包含个人信息、商业秘密和未公开信息。默认不进入开发环境；确需处理时遵循目的限定、最小化、隔离、可追踪和可删除原则。

## 1. 数据分级

| 等级 | 示例 | 默认处理 |
|---|---|---|
| `PUBLIC` | 官方法规、交易所公告、上市公司公开披露文件 | 可进入公共知识区，保留来源 |
| `INTERNAL` | 内部治理制度、非敏感工作底稿 | 仅限所属组织，禁止公开训练 |
| `CONFIDENTIAL` | 身份证件、联系方式、合同、未公开会议材料 | 加密、严格授权、禁止进入开发环境 |
| `RESTRICTED` | 未公开重大事项、监管调查材料、特定敏感个人信息 | 默认拒绝上传；例外须负责人和数据保护责任人批准 |

数据分级由上传者申报，后端扫描只作辅助；不确定时按更高等级处理。

## 2. 环境与用途

- 本地与 CI：仅使用合成数据或不可逆匿名化样本。
- 测试环境：原则上使用脱敏副本，与生产账号、密钥和对象存储隔离。
- 生产环境：按组织隔离，材料只用于用户明确发起的检索、事实提取和合规检查。
- 未经单独、明确授权，不把用户材料用于模型训练、通用 Eval 或跨客户检索。

## 3. 采集与脱敏

上传前说明目的、数据类别、保存期限和可见范围。仅提取完成任务所需字段；身份证号、手机号、邮箱、住址、银行账户和签名图像默认遮蔽。事实层保存结构化命题，证据层保存原件或定位信息，二者不得合并为静态字段。

LLM 只接收任务所需的最小片段；发送前执行脱敏和租户校验。模型输出属于未验证候选，不自动成为 `Fact`、`Evidence` 或法律结论。

## 4. 存储与访问

- 传输使用 TLS，数据库和对象存储启用静态加密。
- 对象使用不可预测 ID；下载采用短时授权地址。
- 应用账号最小权限，生产运维默认不能查看证据正文。
- 证据访问、预览、下载、导出和删除全部记录审计事件。
- 备份继承原数据等级、区域、加密和保存期限。

## 5. 保存与删除

默认建议：上传原件 180 天、派生事实保留至事项关闭后 3 年、审计日志保留 3 年；实际期限由组织政策和法定义务覆盖。到期执行可验证删除，法律保全或争议处理期间暂停删除并记录依据。删除请求应覆盖主存储、搜索索引、向量索引、缓存和可独立恢复的备份周期。

## 6. 安全事件

发现越权访问、误传、外泄或错误跨租户检索时：立即冻结相关访问，保全审计记录，评估影响范围，通知安全与业务负责人，按适用法律和合同决定通知，并将问题加入回归测试。不得让 Agent 自主决定是否上报。

## 7. 上线验收

- [ ] 数据目录、分级责任人和处理目的已登记。
- [ ] 开发、测试、生产环境隔离已验证。
- [ ] 跨租户访问和导出对抗测试通过。
- [ ] 脱敏规则、密钥轮换、备份恢复和删除流程已演练。
- [ ] 外部模型供应商、处理地域、日志保留和退出机制已评审。
- [ ] UI 明示 AI 辅助边界，发布法律结论仍需人工复核。
