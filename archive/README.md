# 归档说明

> 归档日期：2026-07-20。

本目录下的文档描述的是 lawfocus 项目**此前**的定位——一套面向上市公司治理的企业级合规推理系统：确定性规则引擎、五值逻辑执行、规则草稿/审核/发布状态机、RBAC + 多租户、审计追踪、真实公司材料治理。

项目定位已收敛为：**个人/团队用的法律体系学习工具**——给定一部法律（公司法、合同法……），把其中的概念在整个法律体系内做穿透式溯源，帮助理解概念定义、上下位关系和跨法引用；不做企业合规判断，不需要治理事实录入、规则引擎或审核发布工作流。

现行有效的文档见仓库根目录：`00-项目文档索引与实施顺序.md`、`01-法律体系概念图谱设计.md`、`02-学习工具产品需求与验收标准.md`。

保留本目录仅为历史参照，不代表当前范围。`apps/` 下的 FastAPI + Vue 代码仍是按旧定位搭建的骨架，尚未按新方向重建，见根目录 `CLAUDE.md` 说明。
